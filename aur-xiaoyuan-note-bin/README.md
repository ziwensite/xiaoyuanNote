# xiaoyuanNote AUR Package

This directory contains the source for the **`xiaoyuan-note-bin`** package on the
[Arch User Repository (AUR)](https://aur.archlinux.org/packages/xiaoyuan-note-bin).

## Published package

[![AUR](https://img.shields.io/aur/version/xiaoyuan-note-bin)](https://aur.archlinux.org/packages/xiaoyuan-note-bin)

The package is published on AUR and kept in sync with the latest xiaoyuanNote release
via a daily auto-update job that checks GitHub releases.

## Install

```sh
# With an AUR helper (yay / paru)
yay -S xiaoyuan-note-bin

# Or manually
git clone https://aur.archlinux.org/xiaoyuan-note-bin.git
cd xiaoyuan-note-bin
makepkg -si
```
